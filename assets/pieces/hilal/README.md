# Hilal taş seti

Colin M.L. Burnett'in "cburnett" satranç taşlarından türetilmiştir; şah taşında haç, fil taşında gönyedeki artı yerine hilal kullanılır.
Kaynaklar `hilal_{w,b}K.svg`, `hilal_{w,b}B.svg`; 1x/2x/3x webp'ler bunlardan `magick` ile (128/256/384 px) üretilir.
